# Учебный тренажёр учёта и программирования

Независимый прототип для знакомства с понятиями 1С на планшете. Это **не оригинальная платформа 1С**, не её копия и не продукт компании 1С. Он не открывает базы 1С, не совместим с её конфигурациями и не предназначен для реального бухгалтерского, налогового или кадрового учёта. Все примеры и расчёты упрощённые, включая ставки налогов и складской учёт.

Доступны окно запуска с режимами «Предприятие» и «Конфигуратор», панель разделов, вкладки рабочих окон, поиск по справочникам, редактор учебных модулей (Ctrl+S для сохранения, F5 для выполнения), учебные справочники, проведение учебного документа с несколькими строками и просмотр его движений, проводки и ОСВ, ограниченные учебные интерпретаторы запросов и BSL, 12 текстов уроков. Важные ограничения: настоящего конфигуратора, печатных форм, полноценного языка запросов и BSL нет. Учебное дерево метаданных позволяет описать собственный справочник или документ с одним строковым реквизитом, но не создаёт настоящие таблицы и формы 1С. Формулировки уроков могут описывать оригинальную платформу, а не функции прототипа. Проверки уроков приблизительные. Работайте только с вымышленными данными.

Данные и прогресс хранятся в локальном хранилище приложения/браузера и могут быть потеряны при удалении приложения или очистке данных. На экране запуска доступны экспорт и восстановление учебной базы в собственном формате JSON (это не файл .dt 1С). Проверяйте наличие резервной копии: загрузка файла на Android зависит от возможностей устройства и ещё не проверялась на планшете.

## Запуск в браузере

```sh
npm ci
npm run dev
```

Проверки: `npm test` (движки) и `npm run test:ui` (сценарии интерфейса в jsdom; это не проверка на Android-устройстве).

## Android APK

В репозитории подготовлен проект Capacitor и GitHub Actions `.github/workflows/android.yml`. После публикации изменений в текущую ветку можно запустить **Actions → Android debug APK → Run workflow** и скачать артефакт `learning-simulator-debug-apk`. Это отладочный APK, не подписанный для публикации в магазине; при установке Android может предупредить о неизвестном источнике. Сборка требует Android SDK и Java 17.

Локальная сборка на компьютере с установленными Android SDK и Java 17:

```sh
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.

Учебные модули — только текстовые примеры, их редактирование не меняет алгоритмы приложения. F5 выполняет текущий текст в ограниченном учебном интерпретаторе, а не в настоящей платформе 1С.

Отладочные APK из разных запусков GitHub Actions могут иметь разные подписи. Если Android откажется обновить ранее установленную версию, не удаляйте её без резервной копии: удаление приложения может стереть учебные данные.

Значок Android адаптирован из [логотипа компании «1С»](https://ru.wikipedia.org/wiki/Файл:Логотип_компании_«1С».png); товарный знак принадлежит его правообладателю. Приложение не является официальным продуктом 1С и не связано с компанией.
